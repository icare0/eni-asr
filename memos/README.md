# Mémos Pratiques & Référentiels d'Exploitation

Ce dossier regroupe les référentiels de commandes rapides, les synthèses de consoles et les guides de dépannage pour l'administrateur systèmes et réseaux.

---

## Sommaire des Mémos

* **[Consoles MMC, Applets et Raccourcis Clavier](consoles-mmc-raccourcis.md)** : Référentiel des consoles `.msc`, applets `.cpl` et raccourcis pour Server Manager et les sessions Bureau à distance (RDP).
* **[Cheatsheet PowerShell Administrateur](powershell-cheatsheet.md)** : Cmdlets courantes pour Active Directory, gestion des disques, partages SMB et commandes à distance.
* **[Commandes Réseau, Active Directory et Diagnostic](commandes-reseau-diagnostic.md)** : Utilitaires de test et de validation d'infrastructure (`netdom`, `nltest`, `Test-NetConnection`, `repadmin`, `dcdiag`, `gpresult`, `logman`).
