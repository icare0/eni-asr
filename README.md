1. **La barre de recherche en haut à gauche** : Tapez n'importe quel mot-clé (ex: `FSMO`, `AGDLP`, `PSO`, `WAC`, `gpupdate`, `VLAN`). La recherche est instantanée et analyse l'intégralité du texte de tous les cours et TP.
2. **[L'Index Thématique & Mots-clés](/index-thematique.md)** : Un tableau complet recensant chaque notion par ordre alphabétique avec le lien direct vers le cours ou TP concerné.
3. **La barre latérale repliable (Sidebar Accordéon)** : Seule la section que vous consultez s'ouvre, évitant d'afficher une liste infinie de chapitres.
